# Calculadora Online

Calculadora em HTML, CSS e JavaScript com testes em Jest e pipeline no GitHub Actions
(testes em todo push/PR e deploy no GitHub Pages a partir da `main`).

## Rodar localmente
```bash
npm install
npm test
```
Abra `index.html` no navegador.

## Fluxo de branches (Gitflow)
`main` (produção) · `develop` (integração) · `feature/*` · `release/*` · `hotfix/*`
